# Word/Token Counter

Live word, character, and estimated LLM token counts for text you type or paste. Browser-only.

## Local preview

From the monorepo root:

```bash
npm run dev
```

Open [http://localhost:8765/word-token-counter/](http://localhost:8765/word-token-counter/).

## Deploy

Ships with the platform build (`dist/word-token-counter/`). Public entry:
`https://tools.neonema.com/word-token-counter/`. See [docs/DEPLOY.md](../../docs/DEPLOY.md).
