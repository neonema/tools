A few that I think have real ranking potential (mediocre incumbents, clear search intent, low Google-widget risk):
The "JSON syntax error explainer" idea is genuinely under-served. Every developer hits cryptic JSON parse errors and the existing tools just regurgitate the error message. A tool that says "you have a trailing comma on line 14, here's the fix" would get bookmarked.
JSON-to-typed-language converters (TypeScript, Zod, Pydantic, Go, Rust) are individually searched a lot and the existing tools — quicktype is the big one — are okay but not great for the long tail of "JSON to Zod" specifically. Each language gets its own page, each ranks separately.
JSONPath/JMESPath/jq playgrounds are searched by people actively trying to learn the syntax. Existing tools are functional but ugly. A clean one with good examples and shareable URLs would do well.
GeoJSON visualizer with a map is more work (you'd need Leaflet or MapLibre) but it's a strong niche — geojson.io is the incumbent and it's good but cluttered.
The JSON size analyzer is a sleeper hit idea — backend devs optimizing API payloads have nowhere good to go for this.
