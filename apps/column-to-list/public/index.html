Convert Column to Comma-Separated List

Paste a column from Excel or a spreadsheet and join it into a list — or split a list back into lines. Everything runs in your browser.

Column to list converter

Presets

Private by design. Joining and splitting happen on your device. NeoNema never sees what you paste.

How to use it

  1. Copy a column of cells from Excel or Google Sheets.
  2. Paste into the input box. Empty rows are dropped when collapse is on.
  3. Copy the joined list and paste it wherever you need it.

Switch to List → column to split a delimited string back into one item per line. Prefix and suffix fields wrap each item (for example ' on both sides) or the whole result (for example ( and )).
