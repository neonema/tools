PDF Editor is provided as-is to edit the text in a PDF, edit its text boxes, or add an image such as a signature, in your browser. Files have to be 20 MB or smaller.

You can change a line or word of text that is part of the page. The original text is removed from the file and your text is written in its place, in the PDF's own font, size, and colour. If the PDF's font doesn't include a letter you type, that letter comes from the same typeface elsewhere in the PDF, or from a free font matched to the original (the same family where one is freely available, otherwise one with the same or the closest letter widths), or as a last resort from the closest standard PDF font. Only those letters change; the page tells you before you download. A font whose maker allows it only for viewing and printing is not used for new text. If the words you change also appear in the document's title, bookmarks, comments, form defaults, or accessibility text, they are changed there too, and data the document no longer uses is removed when you download, so the original wording is not left in the file. Text that can't be removed from the file can't be changed, and the page says so. Text that is rotated, or on a rotated page, can't be changed.

Find and replace changes each match in its own font, size, and colour, so text set in more than one style keeps each style. A match whose new text the PDF's font can't draw, or that spans two text styles, is left unchanged; you can choose to replace the first kind in the closest standard font. Text inside images, such as scanned pages, can't be found.

A text box is a fillable text field already in the PDF. You can edit, move, resize, or remove a text box.

You can add a PNG, JPEG, or WebP image to a page, move it, and resize it; its proportions are kept. If the image has a plain background, such as a signature on paper, that background is made transparent so only the ink is placed on the page; you can keep the background instead. The image is added on top of the page. Password fields and file-path fields are left unchanged. Password-protected PDFs can't be opened.

Text box changes are written in Helvetica, a standard PDF font. The standard fonts used for page text are Helvetica, Times, and Courier. The free fonts are open-licence fonts served from tools.neonema.com/fonts/, each with its licence there; Chinese, Japanese, and Korean are not included. Characters that no available font can draw can't be saved. The download has no watermark and no NeoNema credit in the file. If the PDF has a digital signature, saving changes the file and the signature will no longer verify.

The file is handled locally. We do not store it or the edited copy, and we are not responsible for how you use the result.
