It renders headings, paragraphs, lists, emphasis, code, links, quotes, rules, and pipe tables. It is not a complete Markdown implementation. HTML in the source is shown as text and is not run. Links are limited to http, https, and mailto addresses. Images are not downloaded.

Previews longer than 400,000 characters are refused. We do not guarantee that every Markdown file will match another renderer, do not guarantee uninterrupted service, and are not responsible for how you use the results.
